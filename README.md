# State Observer

Projeto Java 17 gerenciado com Maven.

O namespace principal é `com.example.stateobserver`. As classes são organizadas
nos subpacotes `pedido`, `observer` e `integracaopedidoobserver`.

## Requisitos

- Java 17 ou superior
- Maven 3.8+

## Executar os testes

```bash
mvn test
```

## Executar a aplicação

```bash
mvn compile exec:java
```
